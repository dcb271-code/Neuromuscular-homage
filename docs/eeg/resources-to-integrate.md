## Rules for integrating them

1. **Licence first.** Only the owner's own material, or open-licence material, may have figures copied into `public/`. Everything else is linked, not copied, exactly as the outline's resource map does for Learning EEG, eeg-training.com and EEGmaster.
2. **Facts still need a source.** A number taken from a slide is cited to the slide's own source, not to the slide. If the slide does not give one, find it or leave the number out.
3. **Attribution log.** Any image that ends up in `public/eeg/` gets a row in `public/eeg/ATTRIBUTIONS.md` with author, licence and the change made, the same way `public/atlas/ATTRIBUTION.md` works for the MRI atlas.
4. **Coverage.** After integrating, update `curriculum-coverage.md` (✅ / ⚠️ / ❌) and add a History entry to `improvement-log.md`.
